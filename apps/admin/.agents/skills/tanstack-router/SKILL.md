# TanStack Router (registry pattern)
Authoritative: `context/system_architecture.md §4.1-4.2`.
- `src/routes/` is **registry-only**: each file wires a `path` -> a `component` imported from a feature barrel -> a `beforeLoad` guard. **No JSX, no inline logic.**
- Pathless layout groups (underscore prefix): `_auth/` (guest-only -> `AuthLayout`, `requireGuest`), `_protected/` (authenticated -> `DashboardLayout`, `requireAuth`). MVP screens live under `_protected/` (`/dashboard`, `/financial`, `/transactions`).
- Guards live in `src/middlewares/authMiddleware.ts` (`requireAuth`, `requireGuest`, `requirePermission`) and are called from `beforeLoad`, never inline.
- `routeTree.gen.ts` is generated by the `@tanstack/router-plugin` Vite plugin — **never hand-edit**.
```tsx
export const Route = createFileRoute("/_protected/transactions/")({
  beforeLoad: () => requirePermission("transactions.view"),
  component: TransactionsPage,
});
```
