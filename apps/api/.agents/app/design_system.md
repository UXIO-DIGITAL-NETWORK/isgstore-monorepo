# Design System Brief: Modern-Kalcer Dashboard

**Target Audience:** React Frontend Developer
**Theme:** "Modern-Kalcer", Clean, Blue-Dominant, Professional

## 1. Design Principles

- **Blue-Centric Palette:** Utilizes a blue gradient spectrum (Blue 600 to Blue 900) to convey trust, security, and a high-tech feel.
- **Ethnic-Free Aesthetic:** Strictly avoids traditional Balinese or other regional decorative motifs to maintain a sleek, "Universal Software" appearance.
- **Data Density:** The admin dashboard is optimized to display high data density (e.g., transaction tables and logs) without feeling cluttered.

## 2. Color Palette

| Category   | Hex Code  | Primary UI Usage                                 |
| :--------- | :-------- | :----------------------------------------------- |
| Primary    | `#2563EB` | Call-to-Action buttons, active navigation links. |
| Surface    | `#FFFFFF` | Cards, form containers, data tables.             |
| Background | `#F8FAFC` | Main application canvas.                         |
| Success    | `#10B981` | "Paid" status badges, WhatsApp action buttons.   |

## 3. Typography

- **Primary:** _Plus Jakarta Sans_ (Geometric & Modern) for headings and display text.
- **Mono:** _Roboto Mono_ for financial data, API codes, and numbers to ensure perfect alignment in columns.
